# STC15F104W based thermometer and humidity meter

This project is published at [Hackaday](https://hackaday.io/project/206419-8-pin-mcu-temperature-and-humidity-meter).

These are firmware files in C for SDCC for an 8-pin STC15F104W (8051 descendant) thermometer and humidity meter using an AHT30 sensor driving a TM1637 based 4 digit display.

It uses the [Protothreads library](https://dunkels.com/adam/pt/) by Adam Dunkels. You should adjust the -I option to the SDCC compiler to where the include files are installed.
